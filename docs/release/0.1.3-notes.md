# v0.1.3 · 这是一个提醒版，不是功能版

> **功能没有变化。现在什么都不做，也可以继续用。**

## 这一版在说什么

插件准备改名：`dsh-connect-loomy` → `dsh-connect-desktop`。

原因只有一个：从 0.2.0 起，它不再只接 Loomy，还会接第二家桌面端供应商——**商汤小浣熊（Raccoon）**。名字里钉着 `loomy` 就不再准确；而每接一家供应商就改一次名，对用的人、对维护的人都不划算。所以一次改成中性的 `desktop`：它说的是「复用你本机桌面端已经有的授权」，不是「登录」——登录只是各家不同的实现手段，写进名字里半年就会过期。

**改名发生在 0.2.0，和第二家供应商同版发布**，不会单独发一个「纯改名版」。这一版只是提前把话讲清楚，另外加了两处只打印、不执行的排查入口。

## 你需要做什么

**如果你的 Loomy 和聊天记录现在用着没问题：这一版不需要你做任何事。**

旧版会一直能用，不会因为改名突然失效；它只是不会获得新供应商和新功能。

想在 0.2.0 发布时换到新名字 + 新供应商，到时按下面两个粘贴块走一遍即可。顺序是写死的：**先卸载旧包，再动目录**。反过来（先把目录改名再卸载）会让 `link:` 指向一个不存在的路径，DSH 启动时会直接报插件加载失败。

### 情况 A：从市场装的

第一个块：

```bash
dsh plugin --profile web remove dsh-connect-loomy
```

第二个「块」是在市场里点安装 **DSH Connect Desktop**（该条目随 0.2.0 上线，现在还不存在）。

### 情况 B：从仓库 clone 后 `link:` 装的（README 的主路径）

第一个块同上；第二个块：

```bash
cd ~/Documents
git clone https://github.com/diudiu62/dsh-connect-desktop.git
cd dsh-connect-desktop
pnpm install && pnpm build
dsh plugin --profile web add link:$PWD
```

> `--profile web` 请按你自己的 profile 名替换。两条路径加起来都只有两个粘贴块。

### 不需要做的事

- **不需要导出 / 导入账号。** 插件的数据目录名**不跟着包名走**，仍然是 `~/.dsh/storages/dsh-connect-loomy/`。重装后账号列表、当前账号、随机池开关、积分数字照旧。
- **不需要重新登录，也不需要备份聊天记录。** 路由键与模型标识没有改动，升级后可以就地接着追问旧会话，思考过程不会丢、也不会被降级成正文。
- **不需要现在动手。** 这一版没有任何强制手段，也不会替你自动迁移。

## 0.1.3 具体改了什么

没有新功能、没有行为变化，只有下面四件事：

1. 设置卡片多一条**可关闭的提示条**：出现一次，关掉之后不再出现，重启也不复现。
2. `doctor` 输出末尾多一段迁移信息（数据目录、设置命名空间、两条迁移命令）。
3. 新增 `migrate --print`：**只打印**命令，不执行任何迁移动作。
4. 万一新旧包同时装着，先给一句人话提示和一条可复制的移除命令，而不是把宿主的 `DUPLICATE_ADAPTER` 堆栈直接糊到用户脸上。

数据文件只增字段、不改既有字段语义、不升 schema 版本，所以**可以随时降级回 0.1.2**，账号不会因此丢。发布资产名仍是 `dsh-connect-loomy.tgz`，下载链接不变。

## 回滚

任何时候都能退回旧包名，账号原地不动：

```bash
dsh plugin --profile web remove dsh-connect-desktop
dsh plugin --profile web add github:diudiu62/dsh-connect-loomy
```

然后重启 DSH。

一点已知限制，先说清楚：回滚后，你在 0.2.0 里**改过的设置**（比如把插件关掉、或自定义了接口地址）不会跟着回来——0.2.0 把设置写在新的命名空间里，旧版读的是旧的那一份。数据本身没有被动过，重新点两下就能改回去。

## 认准地址

市场上存在与本项目同名的第三方实现（旧名条目也可能指向它）。装之前请认准仓库的**全限定地址**，只凭包名不足以判断：

- 现在：`https://github.com/diudiu62/dsh-connect-loomy`
- 0.2.0 起：`https://github.com/diudiu62/dsh-connect-desktop`

一个简单的判断方法：本项目**不要求你填 API Key**，也**不要你的密码**——它只读你本机桌面端已经存在的登录态。要求填 key、要求交出密码或扫码授权的「同名插件」，不是这个项目。
